# Institute of Project Controls Website

## 1. Project Description
A premium, modern, enterprise-grade institutional website for the Institute of Project Controls — a professional membership body for project controls practitioners. The website communicates prestige, professional authority, institutional trust, and international relevance. Target audience includes project controls professionals, employers, consultants, academic partners, sponsors, and learners.

## 2. Page Structure
- `/` - Home
- `/membership` - Membership & Recognition
- `/scholarships` - Scholarships
- `/sponsorship` - Sponsorship
- `/awards` - Awards & Prizes
- `/events` - Events
- `/clubs` - Clubs
- `/about` - About Us
- `/contact` - Contact
- `/privacy` - Privacy & Policies

## 3. Core Features
- [x] Sticky premium header with navigation
- [x] Responsive mobile menu (slide-out)
- [x] Global footer with institutional branding
- [x] Hero sections on every page
- [x] Recognition pathway component
- [x] Membership grade cards
- [x] Evidence checklist tables (responsive)
- [x] Policy accordion sections
- [x] Timeline/process component
- [x] Contact form UI
- [x] Smooth scroll reveal animations
- [x] Mobile-first responsive design

## 4. Data Model Design
No database required. This is a static content website. Contact form submissions handled via platform form infrastructure.

## 5. Backend / Third-party Integration Plan
- Supabase: Not required for initial launch
- Shopify: Not required
- Stripe: Not required
- Forms: Use platform form URL for contact form submissions
